# M1 Meaning Implementation Plan

> **For agentic workers:** Execute each task test-first and verify its focused gate before moving on.

**Goal:** Deliver the canonical M1 gate: atomic task-first authoring against the effective metamodel, accepted authoring
work, generated design tokens, and real-window authoring/inspector UX.

**Architecture:** Praxis compiles Change Event actions into a fully validated batch. Mneme persists that batch as
grouped canonical operations terminated by a commit marker, then projects it atomically. The host exposes one
accepted-work command and typed events; the renderer authoring flow consumes only that command and refreshes from
invalidation events.

**Tech Stack:** Rust 2024, Tauri v2, React 19, TypeScript, shadcn/Tailwind design-system proxies, Vitest, Cargo tests,
WebdriverIO, Storybook.

## Global Constraints

- Preserve workspace-canonical, local-first, time-first, typed-IPC, and no-renderer-HTTP invariants.
- M1 authoring is actual-layer/base-case at valid time zero; temporal authoring remains M2.
- User-facing mutation is task-first only; raw typed operation helpers are internal test seams.
- Use TDD, generated IPC bindings, `locales/en.json`, WCAG 2.2 AA, and light/dark visual inspection.
- Do not modify the user's untracked `.claude/settings.json`.

---

### Task 1: Ratify and implement atomic Change Event batches

- Add the ADR and update operation/workspace/M1 contracts.
- Add Change Event metadata, transaction ids, and commit-marker parsing/serialization.
- Add staged validation, atomic append/projection, legacy replay, and crash-recovery tests.

### Task 2: Add accepted authoring work and the task-first IPC surface

- Add `IpcRequest.idempotencyKey`, `WorkQueueClass::Authoring`, the minimal durable run record, bounded queue, terminal
  events, and invalidation.
- Add `workspace_apply_change_event` and `workspace_inspect_object`; regenerate bindings/manifest/permissions.
- Remove renderer access to direct typed-node/edge and legacy raw-operation commands.

### Task 3: Generate the design-token contract

- Add DTCG reference/semantic token sources and a Style Dictionary generator.
- Generate CSS/shadcn aliases/TypeScript facade and enforce drift through `design:guard`.
- Add token generation and semantic-only consumption tests.

### Task 4: Deliver Modelling Studio authoring and inspector UX

- Add stories first, then metamodel-driven entity/relationship Change Event forms in the Modelling Studio.
- Drive global node/edge selection and the shared inspector through `workspace_inspect_object`.
- Render validation, accepted, completed, failed, backpressure, loading, empty, and provenance states without optimistic
  saved state.

### Task 5: Execute and close the M1 gate

- Run engine/storage/host/renderer targeted tests and the real Tauri golden journey.
- Inspect Storybook and native screenshots in light/dark at representative widths.
- Run `pnpm run ci`, CodeScene/Codacy checks, localisation sync, and update milestone evidence/docs.
- Rehome or close non-gating and duplicate M1 issues before marking the milestone complete.
